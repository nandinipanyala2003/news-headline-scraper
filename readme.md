# 📰 News Headline Scraper 🚀

A powerful and lightweight Python-based web scraper designed to extract trending news headlines from multiple sources in real-time.

---

## ✨ Key Features

🔹 🌐 Scrapes headlines from multiple news websites
🔹 📄 Exports data into structured **JSON** & **CSV** formats
🔹 🔍 Supports keyword-based filtering
🔹 ⚠️ Robust error handling & logging system
🔹 ⏱️ Built-in delay to respect scraping ethics & website policies

---

## ⚙️ Tech Stack

💻 Python
📦 requests
🍲 BeautifulSoup (bs4)

---

## ▶️ How to Run

```bash
pip install -r requirements.txt
python main.py
```

---

## 📁 Output

📂 `data/headlines.json` → Structured JSON data
📂 `data/headlines.csv` → Tabular CSV data
📂 `logs/scraper.log` → Error logs (if any)
